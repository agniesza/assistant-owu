# Asystent OWU

Asystent AI odpowiadający na pytania o ogólne warunki ubezpieczenia (OWU)
na podstawie publicznych dokumentów, z cytatem źródłowym.
Stack (docelowo): Java, Spring AI, RAG (pgvector), MCP, ewaluacja LLM.
